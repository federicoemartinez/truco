# Jugar con un amigo online Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two friends play a full match, each on their own phone, over WebRTC P2P with no server of our own: the inviter's phone hosts and checks every move, the guest's phone draws what it is sent.

**Architecture:** `src/trust.ts` holds identities (ECDSA keys in IndexedDB, id = hash of the public key, room = the host's id) and the signed proof tied to the connection's DTLS fingerprints. `src/online.ts` is pure, tested logic: message parsing that rebuilds everything the other phone sends, the table rules (who sits, both "ready", the guest's moves resolved against the engine) and the gate that lets a peer's messages through only after its proof checks out. `src/net.ts` wraps Trystero; `src/friend.ts` drives a match against a friend (host or guest); `src/main.ts` routes the UI to the CPU match or to `friend.ts`.

**Tech Stack:** TypeScript, Vite 8 (`base: './'`), Node's built-in test runner (`node --test`, TypeScript run directly by Node), Web Crypto (ECDSA P-256, SHA-256), IndexedDB, `@trystero-p2p/nostr` 0.26.0, `qrcode-generator` 2.0.4.

**Spec:** `docs/superpowers/specs/2026-10-31-online-design.md`

## Global Constraints

- Branch `feat/online`, which starts from `feat/pwa-install` (menu without CrazyGames, install button). If `feat/pwa-install` was merged when you start, `git rebase master` first.
- Identifiers and comments in English; UI text in rioplatense Spanish (voseo). Domain values as named constants (`CALL.envido`, not `'envido'`).
- Only two new dependencies: `@trystero-p2p/nostr` and `qrcode-generator`. Everything else is the browser's own (Web Crypto, IndexedDB, `navigator.share`, `navigator.clipboard`).
- Everything that arrives over the network is untrusted: it goes through `parseMsg`/`parseView` (which rebuild it) before anything else touches it, and names are shown only through `esc()`.
- Only actions taken from `legalActions(state, 1)` enter the host's `State`.
- The private key is generated non-extractable and never leaves IndexedDB.
- Online matches use no luck (`newMatch(rng)`, luck `null`) and no CPU notebook (`learn`, `noteCall`).
- Names: at most 24 characters (`NAME_MAX`), no control or invisible formatting characters.
- The friend speaks with `VOICES.aristoteles`; you speak with `PLAYER_VOICE`.
- Commands: `npm test`, `npm run test:sim`, `npm run check`, `npm run build`. All four pass at the end of every task.
- Push with the personal SSH key to `federicoemartinez/truco`; never through `gh` with another account.

## Review Focus

- A guest's "Siguiente mano" sent in the middle of a round must not deal a new round → Task 3, `markReady` test.
- A guest's move out of turn, or with a card they don't hold, must be dropped, not thrown → Task 3, `legalMove` test.
- A rematch after a match that ended in round 1 (same round number, shorter log) must still make the guest hear the new events → Task 3, `newEvents` test.
- A friend whose name is empty or only invisible characters shows as "Tu amigo" → Task 2, `cleanName` test (returns `''`; `friend.ts` falls back to `T.someone`).
- Someone else opening the link while a saved match waits for its guest must get "sala ocupada", not the seat → Task 3, `seat` test.

```ts
// Who is who at an online table. Every player has an ECDSA key pair made on their phone; the private
// key can sign but never be read out. A player's id is the hash of their public key, and their room is
// their id, so whoever opens a room can prove it's theirs
export type Identity = { id: string; publicKey: string; privateKey: CryptoKey } // publicKey: raw, base64url

const ALGO = { name: 'ECDSA', namedCurve: 'P-256' } as const
const SIGN = { name: 'ECDSA', hash: 'SHA-256' } as const
const PROOF_TAG = 'truco-v1' // a signature for this game and this version only

// Lengths in base64url: a raw P-256 key is 65 bytes, a nonce 16, an id (SHA-256) 32, a signature 64
export const KEY_LENGTH = 87
export const NONCE_LENGTH = 22
export const SIG_LENGTH = 86
export const ID_PATTERN = /^[A-Za-z0-9_-]{43}$/

export const isB64 = (x: unknown, length: number): x is string =>
  typeof x === 'string' && x.length === length && /^[A-Za-z0-9_-]+$/.test(x)

export function toB64(bytes: ArrayBuffer | Uint8Array): string {
  return btoa(String.fromCharCode(...new Uint8Array(bytes))).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '')
}

export function fromB64(s: string): Uint8Array<ArrayBuffer> {
  if (!/^[A-Za-z0-9_-]*$/.test(s)) throw new Error('not base64url')
  return Uint8Array.from(atob(s.replace(/-/g, '+').replace(/_/g, '/')), (ch) => ch.charCodeAt(0))
}

export async function idOf(publicKey: string): Promise<string> {
  return toB64(await crypto.subtle.digest('SHA-256', fromB64(publicKey)))
}

export async function newIdentity(): Promise<Identity> {
  const pair = await crypto.subtle.generateKey(ALGO, false, ['sign', 'verify']) // the public half is always readable
  const publicKey = toB64(await crypto.subtle.exportKey('raw', pair.publicKey))
  return { id: await idOf(publicKey), publicKey, privateKey: pair.privateKey }
}

export const newNonce = () => toB64(crypto.getRandomValues(new Uint8Array(16)))

// The DTLS certificate fingerprints in an SDP, sorted. Every WebRTC connection gets its own certificate,
// so they name one connection: a proof signed over them can't be replayed on another
export function fingerprints(sdp: string | undefined): string | null {
  const found = (sdp ?? '').match(/^a=fingerprint:.+$/gm)?.map((line) => line.trim().toLowerCase()).sort()
  return found?.length ? found.join(',') : null
}

const proofText = (nonce: string, signerLocal: string, signerRemote: string) =>
  new TextEncoder().encode([PROOF_TAG, nonce, signerLocal, signerRemote].join('|'))

// "I hold this key, on this connection": a signature over the other side's nonce and both fingerprints
export async function prove(me: Identity, theirNonce: string, local: string, remote: string): Promise<string> {
  return toB64(await crypto.subtle.sign(SIGN, me.privateKey, proofText(theirNonce, local, remote)))
}

// Checks a proof; the signer's local fingerprint is the verifier's remote one
export async function verify(publicKey: string, sig: string, myNonce: string, local: string, remote: string): Promise<boolean> {
  try {
    const key = await crypto.subtle.importKey('raw', fromB64(publicKey), ALGO, false, ['verify'])
    return await crypto.subtle.verify(SIGN, key, fromB64(sig), proofText(myNonce, remote, local))
  } catch {
    return false // not a key, not base64url: not them
  }
}

const DB = 'truco'
const STORE = 'keys'
const ME = 'me'

function request<T>(r: IDBRequest<T>): Promise<T> {
  return new Promise((resolve, reject) => {
    r.onsuccess = () => resolve(r.result)
    r.onerror = () => reject(r.error)
  })
}

// This phone's identity: made once and kept in IndexedDB, which stores the key itself (not its bytes),
// so the page can use it but nothing can copy it out
export async function loadIdentity(): Promise<Identity> {
  try {
    const open = indexedDB.open(DB, 1)
    open.onupgradeneeded = () => open.result.createObjectStore(STORE)
    const db = await request(open)
    const stored: { publicKey: string; privateKey: CryptoKey } | undefined = await request(db.transaction(STORE).objectStore(STORE).get(ME))
    if (stored) return { ...stored, id: await idOf(stored.publicKey) }
    const fresh = await newIdentity()
    await request(db.transaction(STORE, 'readwrite').objectStore(STORE).put({ publicKey: fresh.publicKey, privateKey: fresh.privateKey }, ME))
    return fresh
  } catch (err) {
    console.warn(err) // no IndexedDB (some private windows): an identity for this page only
    return newIdentity()
  }
}
```

```ts
import { BET, CALL, ENVIDO_CALLS, RANKS, REASON, SUITS, WIN } from './engine.ts'
import type { Action, Card, GameEvent, Pending, Player, PlayerView, Trick } from './engine.ts'
import { KEY_LENGTH, NONCE_LENGTH, SIG_LENGTH, isB64 } from './trust.ts'

// What the two phones say to each other (see docs/superpowers/specs/2026-10-31-online-design.md)
export type Msg =
  | { type: 'hello'; key: string; name: string; nonce: string } // base64url; both ways, on every join
  | { type: 'proof'; sig: string } // base64url
  | { type: 'busy' } // host → someone who isn't this match's guest
  | { type: 'view'; view: PlayerView } // host → guest
  | { type: 'action'; action: Action } // guest → host
  | { type: 'ready' } // "Siguiente mano" or "Revancha"
  | { type: 'bye' } // left the match on purpose
export type Hello = Extract<Msg, { type: 'hello' }>

export const NAME_MAX = 24
const SENT_NAME_MAX = 200 // longer than any honest name, cut to NAME_MAX anyway
const LOG_MAX = 64 // a round has far fewer events
const ROUND_MAX = 999
const LEGAL_MAX = 12

// Everything below reads what the other phone sent: never trust it. Each parser builds a fresh object
// out of checked parts, or returns null for anything off by a single field
type Obj = Record<string, unknown>

const typeOf = (x: unknown) => (typeof x === 'object' && x !== null ? (x as Obj).type : undefined)

// A plain object with exactly these keys, plus any of the optional ones
function shape(x: unknown, keys: string[], optional: string[] = []): Obj | null {
  if (typeof x !== 'object' || x === null || Array.isArray(x)) return null
  if (Object.keys(x).some((k) => !keys.includes(k) && !optional.includes(k))) return null
  return keys.every((k) => Object.hasOwn(x, k)) ? (x as Obj) : null
}

const int = (x: unknown, min: number, max: number): x is number => Number.isInteger(x) && (x as number) >= min && (x as number) <= max
const oneOf = <T>(x: unknown, values: readonly T[]): x is T => values.includes(x as T)
const isPlayer = (x: unknown): x is Player => x === 0 || x === 1

// Every item parsed, or null if one fails or there are too many
function list<T>(x: unknown, max: number, item: (y: unknown) => T | null): T[] | null {
  if (!Array.isArray(x) || x.length > max) return null
  const out: T[] = []
  for (const y of x) {
    const parsed = item(y)
    if (parsed === null) return null
    out.push(parsed)
  }
  return out
}

// No control or invisible formatting characters (they can flip the text around), at most NAME_MAX
// whole characters
export function cleanName(name: string): string {
  return Array.from(name.replace(/\p{C}/gu, '').trim()).slice(0, NAME_MAX).join('').trim()
}

const CALLS = Object.values(CALL)
const REASONS = Object.values(REASON)
const BETS = Object.values(BET)
const PHASES = ['playing', 'roundOver', 'matchOver'] as const

function parseCard(x: unknown): Card | null {
  const o = shape(x, ['rank', 'suit'])
  return o && oneOf(o.rank, RANKS) && oneOf(o.suit, SUITS) ? { rank: o.rank, suit: o.suit } : null
}

export function parseAction(x: unknown): Action | null {
  const t = typeOf(x)
  switch (t) {
    case 'play': {
      const o = shape(x, ['type', 'card'])
      const card = o && parseCard(o.card)
      return card ? { type: t, card } : null
    }
    case 'call': {
      const o = shape(x, ['type', 'call'])
      return o && oneOf(o.call, CALLS) ? { type: t, call: o.call } : null
    }
    case 'accept': case 'decline': case 'fold':
      return shape(x, ['type']) ? { type: t } : null
    default:
      return null
  }
}

function parseEvent(x: unknown): GameEvent | null {
  const t = typeOf(x)
  switch (t) {
    case 'play': {
      const o = shape(x, ['type', 'player', 'card'])
      const card = o && parseCard(o.card)
      return o && card && isPlayer(o.player) ? { type: t, player: o.player, card } : null
    }
    case 'call': {
      const o = shape(x, ['type', 'player', 'call'], ['again'])
      if (!o || !isPlayer(o.player) || !oneOf(o.call, CALLS)) return null
      if (!Object.hasOwn(o, 'again')) return { type: t, player: o.player, call: o.call }
      return o.again === true ? { type: t, player: o.player, call: o.call, again: true } : null
    }
    case 'accept': case 'decline': case 'fold': case 'sonBuenas': {
      const o = shape(x, ['type', 'player'])
      return o && isPlayer(o.player) ? { type: t, player: o.player } : null
    }
    case 'envidoPoints': {
      const o = shape(x, ['type', 'player', 'points'])
      return o && isPlayer(o.player) && int(o.points, 0, 33) ? { type: t, player: o.player, points: o.points } : null
    }
    case 'show': {
      const o = shape(x, ['type', 'player', 'cards'])
      const cards = o && list(o.cards, 3, parseCard)
      return o && cards && isPlayer(o.player) ? { type: t, player: o.player, cards } : null
    }
    case 'score': {
      const o = shape(x, ['type', 'player', 'points', 'reason'])
      return o && isPlayer(o.player) && int(o.points, 0, WIN) && oneOf(o.reason, REASONS)
        ? { type: t, player: o.player, points: o.points, reason: o.reason } : null
    }
    default:
      return null
  }
}

function parseTrick(x: unknown): Trick | null {
  const o = shape(x, ['cards', 'winner'])
  const raw = o?.cards
  if (!o || !Array.isArray(raw) || raw.length !== 2) return null
  const cards = raw.map((card) => (card === null ? null : parseCard(card)))
  if (cards.some((card, i) => card === null && raw[i] !== null)) return null
  const winner = o.winner
  if (!(winner === null || winner === 'tie' || isPlayer(winner))) return null
  return { cards: [cards[0], cards[1]], winner }
}

function parsePending(x: unknown): Pending | null {
  const o = shape(x, ['kind', 'caller'])
  return o && oneOf(o.kind, BETS) && isPlayer(o.caller) ? { kind: o.kind, caller: o.caller } : null
}

const VIEW_KEYS = ['round', 'score', 'firstPlayer', 'tricks', 'turn', 'resumeTurn', 'pending', 'trucoLevel', 'raiseRights',
  'envidoCalls', 'envidoDone', 'phase', 'winner', 'log', 'luck', 'me', 'hand', 'dealt', 'opponentHandSize', 'legal']

export function parseView(x: unknown): PlayerView | null {

  if (!o) return null
  const score = list(o.score, 2, (s) => (int(s, 0, WIN) ? s : null))
  const tricks = list(o.tricks, 3, parseTrick)
  const pending = list(o.pending, 3, parsePending)
  const envidoCalls = list(o.envidoCalls, 4, (call) => (oneOf(call, ENVIDO_CALLS) ? call : null))
  const log = list(o.log, LOG_MAX, parseEvent)
  const hand = list(o.hand, 3, parseCard)
  const dealt = list(o.dealt, 3, parseCard)
  const legal = list(o.legal, LEGAL_MAX, parseAction)
  if (!score || score.length !== 2 || !tricks?.length || !pending || !envidoCalls || !log || !hand || !dealt || !legal) return null
  if (!int(o.round, 1, ROUND_MAX) || !isPlayer(o.firstPlayer) || !isPlayer(o.turn) || !isPlayer(o.resumeTurn)) return null
  if (!int(o.trucoLevel, 0, 3) || !(o.raiseRights === null || isPlayer(o.raiseRights)) || typeof o.envidoDone !== 'boolean') return null
  if (!oneOf(o.phase, PHASES) || !(o.winner === null || isPlayer(o.winner)) || o.luck !== null || o.me !== 1) return null
  if (!int(o.opponentHandSize, 0, 3)) return null
  return {
    round: o.round, score: [score[0], score[1]], firstPlayer: o.firstPlayer, tricks, turn: o.turn, resumeTurn: o.resumeTurn,
    pending, trucoLevel: o.trucoLevel, raiseRights: o.raiseRights, envidoCalls, envidoDone: o.envidoDone, phase: o.phase,
    winner: o.winner, log, luck: null, me: 1, hand, dealt, opponentHandSize: o.opponentHandSize, legal,
  }
}

export function parseMsg(x: unknown): Msg | null {
  const t = typeOf(x)
  switch (t) {
    case 'hello': {
      const o = shape(x, ['type', 'key', 'name', 'nonce'])
      return o && isB64(o.key, KEY_LENGTH) && typeof o.name === 'string' && o.name.length <= SENT_NAME_MAX && isB64(o.nonce, NONCE_LENGTH)
        ? { type: t, key: o.key, name: cleanName(o.name), nonce: o.nonce } : null
    }
    case 'proof': {
      const o = shape(x, ['type', 'sig'])
      return o && isB64(o.sig, SIG_LENGTH) ? { type: t, sig: o.sig } : null
    }
    case 'busy': case 'ready': case 'bye':
      return shape(x, ['type']) ? { type: t } : null
    case 'action': {
      const o = shape(x, ['type', 'action'])
      const action = o && parseAction(o.action)
      return action ? { type: t, action } : null
    }
    case 'view': {
      const o = shape(x, ['type', 'view'])
      const view = o && parseView(o.view)
      return view ? { type: t, view } : null
    }
    default:
      return null
  }
}
```

```ts
// The host's match against a friend: the state, who already said "next", and who the guest is
export type Match = { state: State; ready: [boolean, boolean]; guestKey: string; guestName: string }

// Who gets the guest's chair: anyone while no match is on, else only that match's guest
export function seat(guestKey: string | null, key: string): 'new' | 'resume' | 'busy' {
  if (guestKey === null) return 'new'
  return key === guestKey ? 'resume' : 'busy'
}

// A player's "next" at the end of a round or match; once both said it, the next deal (a new match
// after the last round)
export function markReady(m: Match, p: Player, rng: Rng): Match {
  if (m.state.phase === 'playing') return m // a "next" in the middle of a round means nothing
  const ready: [boolean, boolean] = [m.ready[0], m.ready[1]]
  ready[p] = true
  if (!ready[0] || !ready[1]) return { ...m, ready }
  const state = m.state.phase === 'matchOver' ? newMatch(rng) : startRound(m.state, rng)
  return { ...m, state, ready: [false, false] }
}

// The engine's own copy of the move the guest asked for, or null if they can't make it now: nothing the
// other phone built goes into the state
export function legalMove(state: State, p: Player, wanted: Action): Action | null {
  return legalActions(state, p).find((a) => sameAction(a, wanted)) ?? null
}

// What the guest hasn't heard yet: the events since its last view, or the whole log of a new deal
export function newEvents(prev: PlayerView | null, next: PlayerView): GameEvent[] {
  if (!prev || prev.round !== next.round || next.log.length < prev.log.length) return next.log
  return next.log.slice(prev.log.length)
}

export function matchFromSaved(raw: string | null): Match | null {
  try {
    const o = JSON.parse(raw ?? 'null')
    if (!isB64(o?.guestKey, KEY_LENGTH) || typeof o.guestName !== 'string') return null
    if (o.state?.phase !== 'playing' && o.state?.phase !== 'roundOver') return null
    return { state: o.state, ready: [false, false], guestKey: o.guestKey, guestName: cleanName(o.guestName) }
```

```ts
// What the gate needs from the network: net.ts gives the real one, tests wire two fakes together
export type Link = {
  send(msg: Msg, peer: string): Promise<void> | void
  fingerprints(peer: string): { local: string; remote: string } | null
}

export type Gate = {
  join(peer: string): Promise<void>
  leave(peer: string): Promise<void>
  receive(peer: string, data: unknown): Promise<void>
}

type Peer = { nonce: string; hello?: Hello; verified: boolean }

// Lets a peer's messages through only once it proved it holds the key it claims, on this very connection.
// One message at a time, in order: a view sent right after a proof waits until the proof is checked
export function createGate(me: Identity, name: () => string, link: Link, on: {
  verified(peer: string, hello: Hello): Promise<void> | void
  message(peer: string, msg: Msg): void
}): Gate {
  const peers = new Map<string, Peer>()
  let queue = Promise.resolve()
  const enqueue = (job: () => Promise<void> | void) => (queue = queue.then(job).catch((err) => console.warn(err)))

  // Introduces ourselves to a peer the first time we hear of it
  const greet = (peer: string): Peer => {
    let p = peers.get(peer)
    if (!p) {
      p = { nonce: newNonce(), verified: false }
      peers.set(peer, p)
      void link.send({ type: 'hello', key: me.publicKey, name: name(), nonce: p.nonce }, peer)
    }
    return p
  }

  async function handle(peer: string, data: unknown) {
    const msg = parseMsg(data)
    if (!msg) return
    const p = greet(peer)
    const fp = link.fingerprints(peer)
    if (msg.type === 'hello') {
      if (p.hello || !fp) return // one introduction per connection
      p.hello = msg
      await link.send({ type: 'proof', sig: await prove(me, msg.nonce, fp.local, fp.remote) }, peer)
    } else if (msg.type === 'proof') {
      if (!p.hello || p.verified || !fp) return
      if (!(await verify(p.hello.key, msg.sig, p.nonce, fp.local, fp.remote))) return
      p.verified = true
      await on.verified(peer, p.hello)
    } else if (p.verified) on.message(peer, msg)
  }

  return {
    join: (peer) => enqueue(() => void greet(peer)),
    leave: (peer) => enqueue(() => void peers.delete(peer)),
    receive: (peer, data) => enqueue(() => handle(peer, data)),
  }
}
```

```ts
import { joinRoom } from '@trystero-p2p/nostr'
import type { Link, Msg } from './online.ts'
import { fingerprints } from './trust.ts'

const APP_ID = 'truco-federicoemartinez' // changing it splits players into tables that can't see each other
const MAX_BYTES = 64 * 1024 // a view is a couple of KB: anything bigger isn't ours

export type Net = Link & { leave(): void }

// The wire between the two phones: public Nostr relays only help them find each other, the game's
// messages go straight from one to the other over WebRTC. Each message is a JSON string
export function joinTable(roomId: string, on: {
  join(peer: string): void
  leave(peer: string): void
  message(peer: string, data: unknown): void
}): Net {
  const room = joinRoom({ appId: APP_ID, maxReceiveBytes: MAX_BYTES }, roomId)
  const wire = room.makeAction<string>('msg')
  room.onPeerJoin = (peer) => on.join(peer)
  room.onPeerLeave = (peer) => on.leave(peer)
  wire.onMessage = (text, { peerId }) => {
    if (typeof text !== 'string') return
    let data: unknown
    try {
      data = JSON.parse(text)
    } catch {
      return // not one of ours
    }
    on.message(peerId, data)
  }
  return {
    send: (msg: Msg, peer: string) => wire.send(JSON.stringify(msg), { target: peer }),
    fingerprints(peer) {
      const pc = room.getPeers()[peer]
      const local = fingerprints(pc?.localDescription?.sdp)
      const remote = fingerprints(pc?.remoteDescription?.sdp)
      return local && remote ? { local, remote } : null
    },
    leave: () => void room.leave(),
  }
}
```

```ts
import { apply, newMatch, view } from './engine.ts'
import type { Action, Player, PlayerView } from './engine.ts'
import { createGate, legalMove, markReady, matchFromSaved, matchToSaved, newEvents, seat } from './online.ts'
import type { Gate, Hello, Match, Msg } from './online.ts'
import { joinTable } from './net.ts'
import type { Net } from './net.ts'
import { idOf } from './trust.ts'
import type { Identity } from './trust.ts'
import { drop, load, save } from './storage.ts'
import { renderGame, showGuestLobby, showHostLobby } from './ui.ts'
import type { Notice } from './ui.ts'
import { T } from './texts.ts'
import * as voice from './voice.ts'

// Playing a friend: the host (player 0) keeps the match and checks every move; the guest (player 1)
// draws what the host sends and asks to play. See docs/superpowers/specs/2026-10-31-online-design.md
const HOST: Player = 0
const GUEST: Player = 1
const FRIEND_VOICE = voice.VOICES.aristoteles // the clip as it was recorded
const voiceOf = (me: Player) => (who: Player) => (who === me ? voice.PLAYER_VOICE : FRIEND_VOICE)

const NAME_KEY = 'truco:name'
const MATCH_KEY = 'truco:online'

export const myName = () => load(NAME_KEY) ?? ''
export const setName = (name: string) => save(NAME_KEY, name)
export const savedMatch = () => matchFromSaved(load(MATCH_KEY))

let net: Net | null = null
let gate: Gate | null = null
let role: 'host' | 'guest' = 'host'
let peer: string | null = null // the other phone, once it proved who it is
let friendName = ''
let notice: Notice = null
let started = false // the table was on screen: leaving now ends the match
let match: Match | null = null // host only
let roomId = '' // guest only
let seen: PlayerView | null = null // guest only: the last view drawn

function connect(me: Identity, room: string) {
  leave()
  const n = joinTable(room, {
    join: (p) => void (net === n && gate?.join(p)),
    leave: (p) => {
      if (net !== n) return
      void gate?.leave(p)
      if (p === peer) lost()
    },
    message: (p, data) => void (net === n && gate?.receive(p, data)),
  })
  net = n
  gate = createGate(me, myName, n, { verified, message })
}

function leave() {
  net?.leave()
  net = null
  gate = null
  peer = null
}

async function verified(p: string, hello: Hello) {
  if (role === 'guest') {
    if ((await idOf(hello.key)) !== roomId) return // only the room's owner hosts it
    peer = p
    friendName = hello.name || T.someone
    notice = null // back from a drop: the host forgot who said "next", so nobody waits
    draw()
    return
  }
  switch (seat(match?.guestKey ?? null, hello.key)) {
    case 'busy':
      void net?.send({ type: 'busy' }, p)
      return
    case 'new':
      match = { state: newMatchState(), ready: [false, false], guestKey: hello.key, guestName: hello.name }
      break
    case 'resume':
      match = { ...match!, ready: [false, false], guestName: hello.name }
  }
  peer = p
  friendName = hello.name || T.someone
  notice = null
  update()
}

function message(p: string, msg: Msg) {
  if (p !== peer) return
  if (role === 'host') {
    if (!match) return
    if (msg.type === 'action') {
      const action = legalMove(match.state, GUEST, msg.action)
      if (!action) return
      act(GUEST, action)
      update()
    } else if (msg.type === 'ready') next(GUEST)
    else if (msg.type === 'bye') friendLeft()
    return
  }
  if (msg.type === 'view') {
    const v = msg.view
    voice.say(newEvents(seen, v), v.firstPlayer, voiceOf(GUEST))
    if (notice === 'waiting' && (seen?.round !== v.round || seen?.phase !== v.phase)) notice = null
    seen = v
    draw()
  } else if (msg.type === 'busy') {
    leave()
    showGuestLobby(myName(), 'busy')
  } else if (msg.type === 'bye') friendLeft()
}

// The friend's phone dropped without saying goodbye: wait for it
function lost() {
  peer = null
  if (!started || notice === 'left') return
  notice = 'paused'
  draw()
}

function friendLeft() {
  notice = 'left'
  if (role === 'host') drop(MATCH_KEY)
  else history.replaceState(null, '', location.pathname) // reloading shouldn't knock on this table again
  leave()
  draw()
}

function draw() {
  const v = role === 'host' ? match && view(match.state, HOST) : seen
  if (!v) return
  started = true
  renderGame(v, friendName, notice)
}

// Host: keep the match, show it, send the guest its view
function update() {
  const m = match!
  if (m.state.phase === 'matchOver') drop(MATCH_KEY)
  else save(MATCH_KEY, matchToSaved(m))
  draw()
  if (peer) void net?.send({ type: 'view', view: view(m.state, GUEST) }, peer)
}

function act(p: Player, action: Action) {
  const m = match!
  const before = m.state.log.length
  m.state = apply(m.state, p, action)
  voice.say(m.state.log.slice(before), m.state.firstPlayer, voiceOf(HOST))
}

function next(p: Player) {
  const before = match!
  match = markReady(before, p, Math.random)
  if (match.state !== before.state) {
    notice = null
    update()
  } else if (p === HOST) {
    notice = 'waiting'
    draw()
  }
}

const newMatchState = () => newMatch(Math.random) // no luck between friends


// Opens this phone's own room and waits for the friend (or for the guest of the saved match)
export function host(me: Identity) {
  role = 'host'
  match = savedMatch()
  notice = null
  started = false
  connect(me, me.id)
  showHostLobby(`${location.origin}${location.pathname}?sala=${me.id}`, myName(), match?.guestName ?? null)
}

export function guest(me: Identity, room: string) {
  role = 'guest'
  roomId = room
  seen = null
  notice = null
  started = false
  connect(me, room)
}

export function action(a: Action) {
  if (!peer || notice) return // nobody to play against right now
  if (role === 'guest') void net?.send({ type: 'action', action: a }, peer)
  else if (match) {
    act(HOST, a)
    update()
  }
}

export function nextRound() {
  if (!peer || notice) return
  if (role === 'host') return next(HOST)
  void net?.send({ type: 'ready' }, peer)
  notice = 'waiting'
  draw()
}

// Leaving the table on purpose: tell the friend, and a match left halfway is over. Leaving the lobby
// before playing keeps a saved match for later
export async function quit() {
  if (peer) await net?.send({ type: 'bye' }, peer)
  if (started && role === 'host') drop(MATCH_KEY)
  leave()
  match = null
  seen = null
}
```
