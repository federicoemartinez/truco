# Truco v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Truco argentino mano a mano contra la máquina, en el navegador, publicable en CrazyGames con el mismo build que sirve para cualquier hosting estático.

**Architecture:** Un motor de reglas puro (`engine.ts`: estado + acción → estado nuevo, sin DOM) es la única puerta para cambiar el estado. La IA (`ai.ts`) y la UI (`ui.ts`) son clientes del motor: ambos reciben una `PlayerView` que trae las acciones legales y nunca la mano rival. `main.ts` une todo y `portal.ts` es una capa fina y opcional sobre el SDK de CrazyGames.

**Tech Stack:** TypeScript 7 + Vite 8 (únicas dependencias, ambas de desarrollo), DOM + CSS + SVG propio, tests con `node --test` (Node 24 ejecuta TS nativo).

**Spec:** `docs/superpowers/specs/2026-10-24-truco-design.md`

## Global Constraints

- Dependencias: solo `vite` y `typescript`, como `devDependencies`. Nada más.
- Identificadores y comentarios en inglés. Todo texto visible al jugador, en castellano rioplatense y dentro de `src/texts.ts`.
- Node ejecuta los `.ts` quitando tipos: imports con extensión `.ts`, imports de solo tipos con `import type`, sin `enum`, `namespace` ni parameter properties.
- Estilo: 2 espacios, comillas simples, sin punto y coma.
- Reglas: a 30 (15 malas + 15 buenas), sin flor, exactamente como la sección "Reglas" del spec.
- CrazyGames: rutas relativas (`base: './'`), `user-select: none`, que ande con mouse, touch y teclado, y descarga inicial ≤ 20 MB.
- El jugador humano es `0` y la máquina es `1`.

## Review Focus

Casos que el spec implica pero que ningún test escribiría solo, con el comportamiento esperado:

1. **Partido terminado por un envido apilado sobre un truco pendiente.** El partido termina en ese momento: no queda nada pendiente y ninguno de los dos tiene acciones legales. Test en la Task 4.
2. **Irse al mazo mientras un envido está apilado sobre un truco.** El rival suma el envido no querido más 1 por la mano. Test en la Task 4.
3. **Puntaje que pasaría de 30** (por ejemplo, 28 + vale cuatro). Queda exactamente en 30 y el evento registra los puntos realmente sumados. Test en la Task 3.
4. **Derecho a subir después de una subida directa.** Si se responde un truco con retruco y el otro lo acepta, el que aceptó puede cantar vale cuatro y el que cantó el retruco no. Test en la Task 3.
5. **Doble toque en mobile.** Un doble toque rápido sobre una carta juega solo esa carta: el segundo toque no dispara otra acción sobre la mesa recién dibujada. Verificación manual en la Task 7.

```ts
export type Suit = 'swords' | 'clubs' | 'coins' | 'cups'
export type Rank = 1 | 2 | 3 | 4 | 5 | 6 | 7 | 10 | 11 | 12
export type Card = { rank: Rank; suit: Suit }
export type Player = 0 | 1
export type Rng = () => number

export const SUITS: Suit[] = ['swords', 'clubs', 'coins', 'cups']
export const RANKS: Rank[] = [1, 2, 3, 4, 5, 6, 7, 10, 11, 12]

export const other = (p: Player): Player => (p === 0 ? 1 : 0)
export const sameCard = (a: Card, b: Card) => a.rank === b.rank && a.suit === b.suit

export function newDeck(): Card[] {
  return SUITS.flatMap((suit) => RANKS.map((rank) => ({ rank, suit })))
}

// Fisher–Yates
export function shuffle<T>(items: T[], rng: Rng): T[] {
  const a = items.slice()
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1))
    const t = a[i]
    a[i] = a[j]
    a[j] = t
  }
  return a
}

// mulberry32: tiny seeded PRNG so tests and fuzzing are reproducible
export function seededRng(seed: number): Rng {
  return () => {
    seed = (seed + 0x6d2b79f5) | 0
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed)
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}

const RANK_POWER: Record<Rank, number> = { 3: 10, 2: 9, 1: 8, 12: 7, 11: 6, 10: 5, 7: 4, 6: 3, 5: 2, 4: 1 }

// Truco hierarchy: higher beats lower, equal power is a tie (parda)
export function cardPower(card: Card): number {
  if (card.rank === 1 && card.suit === 'swords') return 14
  if (card.rank === 1 && card.suit === 'clubs') return 13
  if (card.rank === 7 && card.suit === 'swords') return 12
  if (card.rank === 7 && card.suit === 'coins') return 11
  return RANK_POWER[card.rank]
}

export function envidoPoints(cards: Card[]): number {
  const value = (card: Card) => (card.rank >= 10 ? 0 : card.rank)
  let best = Math.max(...cards.map(value))
  for (let i = 0; i < cards.length; i++) {
    for (let j = i + 1; j < cards.length; j++) {
      if (cards[i].suit === cards[j].suit) best = Math.max(best, 20 + value(cards[i]) + value(cards[j]))
    }
  }
  return best
}
```

```ts
import type { Action, Call, Card, Player, Rank, State, Suit } from '../src/engine.ts'

export const c = (rank: Rank, suit: Suit): Card => ({ rank, suit })

// A fresh round with fixed hands; player 0 is "el mano" unless overridden
export function setup(h0: Card[], h1: Card[], overrides: Partial<State> = {}): State {
  const first: Player = overrides.firstPlayer ?? 0
  return {
    ...newMatch(seededRng(1)),
    firstPlayer: first,
    turn: first,
    resumeTurn: first,
    dealt: [h0, h1],
    hands: [h0.slice(), h1.slice()],
    ...overrides,
  }
}

export function run(state: State, steps: [Player, Action][]): State {
  return steps.reduce((s, [p, a]) => apply(s, p, a), state)
```

```ts
export type EnvidoCall = 'envido' | 'realEnvido' | 'faltaEnvido'
export type TrucoCall = 'truco' | 'retruco' | 'valeCuatro'
export type Call = EnvidoCall | TrucoCall

export type Action =
  | { type: 'play'; card: Card }
  | { type: 'call'; call: Call }
  | { type: 'accept' }
  | { type: 'decline' }
  | { type: 'fold' }

export type GameEvent =
  | { type: 'play'; player: Player; card: Card }
  | { type: 'call'; player: Player; call: Call }
  | { type: 'accept'; player: Player }
  | { type: 'decline'; player: Player }
  | { type: 'fold'; player: Player }
  | { type: 'envidoPoints'; player: Player; points: number }
  | { type: 'sonBuenas'; player: Player }
  | { type: 'score'; player: Player; points: number; reason: 'envido' | 'round' }

export type Trick = { cards: [Card | null, Card | null]; winner: Player | 'tie' | null }
export type Pending = { kind: 'envido' | 'truco'; caller: Player }

export type State = {
  round: number // 1-based, within the match
  score: [number, number]
  firstPlayer: Player // "el mano": leads the first trick and wins ties
  dealt: [Card[], Card[]] // the 3 cards each player got, for envido
  hands: [Card[], Card[]] // cards not played yet
  tricks: Trick[] // the last one is in progress
  turn: Player // who must act now
  resumeTurn: Player // whose play-turn resumes once every call is answered
  pending: Pending[] // unanswered calls; an envido can sit on top of a truco
  trucoLevel: number // accepted bet: 0 none, 1 truco, 2 retruco, 3 vale cuatro
  raiseRights: Player | null // who may raise the truco next; null: anyone
  envidoCalls: EnvidoCall[]
  envidoDone: boolean
  phase: 'playing' | 'roundOver' | 'matchOver'
  winner: Player | null
  log: GameEvent[] // this round's events, for the UI
}

// What one player may know: never the opponent's cards
export type PlayerView = Omit<State, 'dealt' | 'hands'> & {
  me: Player
  hand: Card[]
  dealt: Card[]
  opponentHandSize: number
  legal: Action[]
}

export const WIN = 30

function deal(round: number, score: [number, number], firstPlayer: Player, rng: Rng): State {
  const deck = shuffle(newDeck(), rng)
  const dealt: [Card[], Card[]] = [deck.slice(0, 3), deck.slice(3, 6)]
  return {
    round,
    score,
    firstPlayer,
    dealt,
    hands: [dealt[0].slice(), dealt[1].slice()],
    tricks: [{ cards: [null, null], winner: null }],
    turn: firstPlayer,
    resumeTurn: firstPlayer,
    pending: [],
    trucoLevel: 0,
    raiseRights: null,
    envidoCalls: [],
    envidoDone: false,
    phase: 'playing',
    winner: null,
    log: [],
  }
}

export function newMatch(rng: Rng): State {
  return deal(1, [0, 0], rng() < 0.5 ? 0 : 1, rng)
}

export function startRound(state: State, rng: Rng): State {
  if (state.phase !== 'roundOver') throw new Error('startRound: the round is not over')
  return deal(state.round + 1, [state.score[0], state.score[1]], other(state.firstPlayer), rng)
}

export function legalActions(state: State, p: Player): Action[] {
  if (state.phase !== 'playing' || state.turn !== p) return []
  const actions: Action[] = state.hands[p].map((card) => ({ type: 'play', card }))
  actions.push({ type: 'fold' })
  return actions
}

function sameAction(a: Action, b: Action): boolean {
  if (a.type === 'play' && b.type === 'play') return sameCard(a.card, b.card)
  if (a.type === 'call' && b.type === 'call') return a.call === b.call
  return a.type === b.type
}

// The only way to change the state: validates, then works on a copy
export function apply(state: State, p: Player, action: Action): State {
  if (!legalActions(state, p).some((a) => sameAction(a, action))) {
    throw new Error(`Illegal action by player ${p}: ${JSON.stringify(action)}`)
  }
  const s = structuredClone(state)
  switch (action.type) {
    case 'play': play(s, p, action.card); break
    case 'fold': fold(s, p); break
  }
  return s
}

function play(s: State, p: Player, card: Card) {
  s.log.push({ type: 'play', player: p, card })
  s.hands[p] = s.hands[p].filter((c) => !sameCard(c, card))
  const trick = s.tricks[s.tricks.length - 1]
  trick.cards[p] = card
  const [a, b] = trick.cards
  if (!a || !b) {
    s.turn = other(p)
    return
  }
  const diff = cardPower(a) - cardPower(b)
  trick.winner = diff > 0 ? 0 : diff < 0 ? 1 : 'tie'
  const winner = roundWinner(s.tricks.map((t) => t.winner as Player | 'tie'), s.firstPlayer)
  if (winner !== null) {
    endRound(s, winner)
    return
  }
  s.tricks.push({ cards: [null, null], winner: null })
  s.turn = trick.winner === 'tie' ? s.firstPlayer : trick.winner
}

// results: winners of the completed tricks, in order
export function roundWinner(results: (Player | 'tie')[], firstPlayer: Player): Player | null {
  const wins = (p: Player) => results.filter((r) => r === p).length
  if (wins(0) === 2) return 0
  if (wins(1) === 2) return 1
  const [first, second, third] = results
  if (results.length === 2) {
    if (first === 'tie' && second !== 'tie') return second // 1st tied: the 2nd decides
    if (first !== 'tie' && second === 'tie') return first // 2nd tied: the 1st decides
  }
  if (results.length === 3) {
    if (third !== 'tie') return third
    return first !== 'tie' ? first : firstPlayer
  }
  return null
}

function award(s: State, p: Player, points: number, reason: 'envido' | 'round') {
  if (s.phase === 'matchOver') return
  const added = Math.min(WIN - s.score[p], points)
  s.score[p] += added
  s.log.push({ type: 'score', player: p, points: added, reason })
  if (s.score[p] === WIN) {
    s.phase = 'matchOver'
    s.winner = p
    s.pending = []
  }
}

function endRound(s: State, winner: Player) {
  award(s, winner, s.trucoLevel + 1, 'round')
  s.pending = []
  if (s.phase === 'playing') s.phase = 'roundOver'
}

function fold(s: State, p: Player) {
  s.log.push({ type: 'fold', player: p })
  endRound(s, other(p))
}

export function view(state: State, me: Player): PlayerView {
  const { dealt, hands, ...pub } = structuredClone(state)
  return {
    ...pub,
    me,
    hand: hands[me],
    dealt: dealt[me],
    opponentHandSize: hands[other(me)].length,
    legal: legalActions(state, me),
  }
}
```

```ts
const TRUCO_CALLS: TrucoCall[] = ['truco', 'retruco', 'valeCuatro'] // index = level - 1

export function legalActions(state: State, p: Player): Action[] {
  if (state.phase !== 'playing' || state.turn !== p) return []
  const actions: Action[] = []
  const top = state.pending.at(-1)
  if (top) {
    actions.push({ type: 'accept' }, { type: 'decline' })
    if (state.trucoLevel + 1 < 3) actions.push({ type: 'call', call: TRUCO_CALLS[state.trucoLevel + 1] })
  } else {
    for (const card of state.hands[p]) actions.push({ type: 'play', card })
    if (state.trucoLevel < 3 && (state.raiseRights === null || state.raiseRights === p)) {
      actions.push({ type: 'call', call: TRUCO_CALLS[state.trucoLevel] })
    }
  }
  actions.push({ type: 'fold' })
  return actions
}

// The only way to change the state: validates, then works on a copy
export function apply(state: State, p: Player, action: Action): State {
  if (!legalActions(state, p).some((a) => sameAction(a, action))) {
    throw new Error(`Illegal action by player ${p}: ${JSON.stringify(action)}`)
  }
  const s = structuredClone(state)
  switch (action.type) {
    case 'play': play(s, p, action.card); break
    case 'call': call(s, p, action.call); break
    case 'accept': accept(s, p); break
    case 'decline': decline(s, p); break
    case 'fold': fold(s, p); break
  }
  return s
}

function call(s: State, p: Player, c: Call) {
  s.log.push({ type: 'call', player: p, call: c })
  const top = s.pending.at(-1)
  if (!top) {
    s.resumeTurn = p
    s.pending.push({ kind: 'truco', caller: p })
  } else {
    s.trucoLevel++ // raising accepts the bet on the table
    top.caller = p
  }
  s.turn = other(p)
}

function accept(s: State, p: Player) {
  s.log.push({ type: 'accept', player: p })
  s.pending.pop()
  s.trucoLevel++
  s.raiseRights = p
  resume(s)
}

function decline(s: State, p: Player) {
  s.log.push({ type: 'decline', player: p })
  const top = s.pending.pop()!
  endRound(s, top.caller)
}

// After an answer: the next pending call is answered, or the interrupted play-turn resumes
function resume(s: State) {
  if (s.phase !== 'playing') return
  const top = s.pending.at(-1)
  s.turn = top ? other(top.caller) : s.resumeTurn
}
```

```ts
const ENVIDO_CALLS: EnvidoCall[] = ['envido', 'realEnvido', 'faltaEnvido']
const ENVIDO_VALUE: Record<EnvidoCall, number> = { envido: 2, realEnvido: 3, faltaEnvido: 0 } // falta depends on the score

export const isEnvido = (c: Call): c is EnvidoCall => (ENVIDO_CALLS as Call[]).includes(c)

export function legalActions(state: State, p: Player): Action[] {
  if (state.phase !== 'playing' || state.turn !== p) return []
  const actions: Action[] = []
  const top = state.pending.at(-1)
  if (top) {
    actions.push({ type: 'accept' }, { type: 'decline' })
    if (top.kind === 'envido') {
      for (const name of ENVIDO_CALLS) if (canRaiseEnvido(state.envidoCalls, name)) actions.push({ type: 'call', call: name })
    } else {
      if (state.trucoLevel + 1 < 3) actions.push({ type: 'call', call: TRUCO_CALLS[state.trucoLevel + 1] })
      if (canStartEnvido(state, p)) for (const name of ENVIDO_CALLS) actions.push({ type: 'call', call: name })
    }
  } else {
    for (const card of state.hands[p]) actions.push({ type: 'play', card })
    if (canStartEnvido(state, p)) for (const name of ENVIDO_CALLS) actions.push({ type: 'call', call: name })
    if (state.trucoLevel < 3 && (state.raiseRights === null || state.raiseRights === p)) {
      actions.push({ type: 'call', call: TRUCO_CALLS[state.trucoLevel] })
    }
  }
  actions.push({ type: 'fold' })
  return actions
}

// First trick, before your card, nothing sung yet and no truco accepted ("el envido está primero")
function canStartEnvido(s: State, p: Player): boolean {
  return s.tricks.length === 1 && s.tricks[0].cards[p] === null &&
    s.envidoCalls.length === 0 && !s.envidoDone && s.trucoLevel === 0
}

// Envido may be repeated once; otherwise each call must outrank the previous one
function canRaiseEnvido(calls: EnvidoCall[], next: EnvidoCall): boolean {
  const last = calls[calls.length - 1]
  if (next === 'envido') return calls.length === 1 && last === 'envido'
  return ENVIDO_CALLS.indexOf(next) > ENVIDO_CALLS.indexOf(last)
}

export function faltaPoints(score: [number, number], winner: Player): number {
  const leader = Math.max(...score)
  return leader < 15 ? WIN - score[winner] : WIN - leader
}

export function envidoAcceptedPoints(calls: EnvidoCall[], score: [number, number], winner: Player): number {
  if (calls[calls.length - 1] === 'faltaEnvido') return faltaPoints(score, winner)
  return calls.reduce((sum, c) => sum + ENVIDO_VALUE[c], 0)
}

// Everything but the last call, at least 1 (falta is always last)
export function envidoDeclinedPoints(calls: EnvidoCall[]): number {
  return Math.max(1, calls.slice(0, -1).reduce((sum, c) => sum + ENVIDO_VALUE[c], 0))
}

function call(s: State, p: Player, c: Call) {
  s.log.push({ type: 'call', player: p, call: c })
  const top = s.pending.at(-1)
  if (!top) s.resumeTurn = p
  if (isEnvido(c)) {
    s.envidoCalls.push(c)
    if (top?.kind === 'envido') top.caller = p
    else s.pending.push({ kind: 'envido', caller: p }) // fresh, or on top of a truco
  } else if (top?.kind === 'truco') {
    s.trucoLevel++ // raising accepts the bet on the table
    top.caller = p
  } else {
    s.pending.push({ kind: 'truco', caller: p })
  }
  s.turn = other(p)
}

function accept(s: State, p: Player) {
  s.log.push({ type: 'accept', player: p })
  const top = s.pending.pop()!
  if (top.kind === 'envido') {
    resolveEnvido(s)
  } else {
    s.trucoLevel++
    s.raiseRights = p
  }
  resume(s)
}

function decline(s: State, p: Player) {
  s.log.push({ type: 'decline', player: p })
  const top = s.pending.pop()!
  if (top.kind === 'truco') {
    endRound(s, top.caller)
    return
  }
  s.envidoDone = true
  award(s, top.caller, envidoDeclinedPoints(s.envidoCalls), 'envido')
  resume(s)
}

function fold(s: State, p: Player) {
  s.log.push({ type: 'fold', player: p })
  if (s.pending.at(-1)?.kind === 'envido') {
    s.envidoDone = true
    award(s, other(p), envidoDeclinedPoints(s.envidoCalls), 'envido')
  }
  endRound(s, other(p))
}

// The mano says its points; the pie only says them if they win ("son buenas" otherwise)
function resolveEnvido(s: State) {
  s.envidoDone = true
  const mano = s.firstPlayer
  const pie = other(mano)
  const manoPoints = envidoPoints(s.dealt[mano])
  const piePoints = envidoPoints(s.dealt[pie])
  s.log.push({ type: 'envidoPoints', player: mano, points: manoPoints })
  let winner = mano
  if (piePoints > manoPoints) {
    s.log.push({ type: 'envidoPoints', player: pie, points: piePoints })
    winner = pie
  } else {
    s.log.push({ type: 'sonBuenas', player: pie })
  }
  award(s, winner, envidoAcceptedPoints(s.envidoCalls, s.score, winner), 'envido')
}
```

```ts
import { cardPower, envidoDeclinedPoints, envidoPoints, faltaPoints, isEnvido, other } from './engine.ts'
import type { Action, Call, Card, PlayerView, Rng } from './engine.ts'

// bluff: chance of calling with a bad hand; aggression: lowers the bar to call and accept truco
export type AiParams = { bluff: number; aggression: number }
export const DEFAULT_PARAMS: AiParams = { bluff: 0.15, aggression: 0.5 }

export function chooseAction(v: PlayerView, params: AiParams = DEFAULT_PARAMS, rng: Rng = Math.random): Action {
  const top = v.pending.at(-1)
  if (top?.kind === 'envido') return respondEnvido(v)
  if (top?.kind === 'truco') return respondTruco(v, params, rng)
  return callEnvido(v, params, rng, true) ?? callTruco(v, params, rng) ?? chooseCard(v)
}

function find(v: PlayerView, type: Action['type'], name?: Call): Action | undefined {
  return v.legal.find((a) => a.type === type && (a.type !== 'call' || a.call === name))
}

const trucoCall = (v: PlayerView) => v.legal.find((a) => a.type === 'call' && !isEnvido(a.call))

function callEnvido(v: PlayerView, params: AiParams, rng: Rng, maySandbag: boolean): Action | undefined {
  if (!find(v, 'call', 'envido')) return undefined
  const points = envidoPoints(v.dealt)
  const behind = v.score[other(v.me)] - v.score[v.me]
  // As mano with a great envido, sometimes stay quiet so the opponent calls and we raise
  if (maySandbag && points >= 31 && v.firstPlayer === v.me && rng() < 0.3) return undefined
  if (points >= 30) return find(v, 'call', points >= 32 || behind >= 10 ? 'faltaEnvido' : 'realEnvido')
  if (points >= 27 || rng() < params.bluff) return find(v, 'call', 'envido')
  return undefined
}

function respondEnvido(v: PlayerView): Action {
  const points = envidoPoints(v.dealt)
  const opp = other(v.me)
  const calls = v.envidoCalls
  if (points >= 31) {
    const raise = find(v, 'call', 'realEnvido') ?? (points >= 32 ? find(v, 'call', 'faltaEnvido') : undefined)
    if (raise) return raise
  }
  const declineLosesMatch = v.score[opp] + envidoDeclinedPoints(calls) >= 30
  const isFalta = calls[calls.length - 1] === 'faltaEnvido'
  const faltaCostsMatch = v.score[opp] + faltaPoints(v.score, opp) >= 30
  const threshold = isFalta ? (faltaCostsMatch ? 30 : 28) : 26 + 2 * (calls.length - 1)
  const manoBonus = v.firstPlayer === v.me ? 1 : 0 // the mano wins ties
  if (declineLosesMatch || points >= threshold - manoBonus) return find(v, 'accept')!
  return find(v, 'decline')!
}

function callTruco(v: PlayerView, params: AiParams, rng: Rng): Action | undefined {
  const raise = trucoCall(v)
  if (!raise) return undefined
  if (handStrength(v) >= 0.7 - 0.2 * params.aggression || rng() < params.bluff) return raise
  return undefined
}

function respondTruco(v: PlayerView, params: AiParams, rng: Rng): Action {
  const envido = callEnvido(v, params, rng, false) // el envido está primero
  if (envido) return envido
  const strength = handStrength(v)
  const raise = trucoCall(v)
  if (raise && (strength >= 0.85 - 0.2 * params.aggression || rng() < params.bluff / 2)) return raise
  const declineLosesMatch = v.score[other(v.me)] + v.trucoLevel + 1 >= 30
  if (declineLosesMatch || strength >= 0.55 - 0.2 * params.aggression) return find(v, 'accept')!
  return find(v, 'decline')!
}

// 0..1 estimate of taking the round, from the cards still ours and how the tricks went
function handStrength(v: PlayerView): number {
  const opp = other(v.me)
  const current = v.tricks[v.tricks.length - 1]
  const onTable = current.cards[v.me]
  const powers = [...v.hand, ...(onTable ? [onTable] : [])].map(cardPower).sort((a, b) => b - a)
  if (powers.length === 0) return 0
  const best = powers[0] / 14
  const avg = powers.reduce((a, b) => a + b, 0) / powers.length / 14
  let strength = 0.6 * best + 0.4 * avg
  const done = v.tricks.filter((t) => t.winner !== null)
  strength += 0.25 * (done.filter((t) => t.winner === v.me).length - done.filter((t) => t.winner === opp).length)
  const oppCard = current.cards[opp]
  if (oppCard && !onTable) strength += powers[0] > cardPower(oppCard) ? 0.1 : -0.2
  return Math.min(1, Math.max(0, strength))
}

function chooseCard(v: PlayerView): Action {
  const play = (card: Card): Action => ({ type: 'play', card })
  const weakestFirst = [...v.hand].sort((a, b) => cardPower(a) - cardPower(b))
  const trickIndex = v.tricks.length - 1
  const oppCard = v.tricks[trickIndex].cards[other(v.me)]
  if (oppCard) {
    const target = cardPower(oppCard)
    const winning = weakestFirst.find((card) => cardPower(card) > target)
    if (winning) return play(winning)
    // Tie the first trick if that keeps a 3 or better for later
    const tying = weakestFirst.find((card) => cardPower(card) === target)
    if (tying && trickIndex === 0 && weakestFirst.some((card) => card !== tying && cardPower(card) >= 10)) return play(tying)
    return play(weakestFirst[0])
  }
  if (trickIndex === 0) return play(weakestFirst[Math.floor(weakestFirst.length / 2)])
  // Leading a later trick means we won or tied the first: our best card closes the round
  return play(weakestFirst[weakestFirst.length - 1])
}
```

```ts
import { other, sameCard } from './engine.ts'
import type { Action, GameEvent, Player, PlayerView, Trick } from './engine.ts'
import { SPRITE, backSvg, cardSvg } from './cards.ts'
import { ACTION_LABEL, CALL_LABEL, RULES_HTML, T, cardName, roundSummary, speech } from './texts.ts'

export type Handlers = {
  onStart(): void
  onAction(action: Action): void
  onNextRound(): void
  onRematch(): void
  onMenu(): void
}

type PlayEvent = Extract<GameEvent, { type: 'play' }>

let root: HTMLElement
let current: PlayerView | null = null
let lastRender = 0
let seen = { round: 0, plays: 0, bubbles: [null, null] as (string | null)[] }

export function mount(el: HTMLElement, h: Handlers) {
  root = el
  document.body.insertAdjacentHTML('afterbegin', SPRITE)
  root.addEventListener('click', (e) => {
    const target = (e.target as Element).closest<HTMLElement>('[data-do]')
    switch (target?.dataset.do) {
      case 'start': return h.onStart()
      case 'rules': return root.querySelector<HTMLDialogElement>('#rules')!.showModal()
      case 'next': return h.onNextRound()
      case 'rematch': return h.onRematch()
      case 'menu': return h.onMenu()
      case 'act': {
        // ponytail: time-based guard against a double tap landing on the freshly drawn table; per-render tokens if it misfires
        if (performance.now() - lastRender < 250) return
        const action = current?.legal[Number(target!.dataset.i)]
        if (action) h.onAction(action)
      }
    }
  })
}

export function showMenu() {
  current = null
  seen = { round: 0, plays: 0, bubbles: [null, null] }
  root.innerHTML = `
    <main class="menu">
      <h1>${T.title}</h1>
      <p>${T.subtitle}</p>
      <button class="primary" data-do="start">${T.play}</button>
      <button data-do="rules">${T.rules}</button>
      <dialog id="rules">${RULES_HTML}<form method="dialog"><button>${T.close}</button></form></dialog>
    </main>`
}

export function renderGame(v: PlayerView) {
  current = v
  lastRender = performance.now()
  const opp = other(v.me)
  const newRound = v.round !== seen.round
  const plays = v.log.filter((e): e is PlayEvent => e.type === 'play')
  const lastPlay = !newRound && plays.length > seen.plays ? plays[plays.length - 1] : undefined
  const bubbles = [bubbleText(v, 0), bubbleText(v, 1)]
  const dealCls = newRound ? ' deal' : ''
  const dealStyle = (k: number) => (newRound ? ` style="--k:${k}"` : '')

  const bubble = (p: Player, cls: string) => {
    const text = bubbles[p]
    const pop = text !== seen.bubbles[p] ? ' pop' : ''
    return `<div class="${cls}">${text ? `<span class="bubble${pop}">${text}</span>` : ''}</div>`
  }

  const slot = (trick: Trick | undefined, p: Player) => {
    const card = trick?.cards[p]
    if (!trick || !card) return '<div class="slot"></div>'
    const won = trick.winner === p ? ' won' : ''
    const enter = lastPlay && lastPlay.player === p && sameCard(lastPlay.card, card) ? ' enter' : ''
    return `<div class="slot${won}${enter}" role="img" aria-label="${cardName(card)}">${cardSvg(card)}</div>`
  }

  const tricks = [0, 1, 2]
    .map((i) => `<div class="trick"><span class="label">${T.trick[i]}</span>${slot(v.tricks[i], opp)}${slot(v.tricks[i], v.me)}</div>`)
    .join('')

  const backs = Array.from({ length: v.opponentHandSize }, (_, k) => `<div class="back${dealCls}"${dealStyle(k)}>${backSvg()}</div>`).join('')

  const hand = v.hand.map((card, k) => {
    const i = v.legal.findIndex((a) => a.type === 'play' && sameCard(a.card, card))
    const act = i < 0 ? 'disabled' : `data-do="act" data-i="${i}"`
    return `<button class="card-btn${dealCls}"${dealStyle(k)} ${act} aria-label="${cardName(card)}">${cardSvg(card)}</button>`
  }).join('')

  const buttons = v.legal.map((a, i) => {
    if (a.type === 'play') return ''
    const label = a.type === 'call' ? CALL_LABEL[a.call] : ACTION_LABEL[a.type]
    return `<button class="${a.type}" data-do="act" data-i="${i}">${label}</button>`
  }).join('')

  const thinking = v.phase === 'playing' && v.turn !== v.me ? `<span class="thinking">${T.thinking}</span>` : ''

  root.innerHTML = `
    <main class="table">
      <header class="top">
        <div class="opponent">
          <div class="opp-hand" role="img" aria-label="${T.cpu}: ${v.opponentHandSize}">${backs}</div>
          ${thinking}
          ${bubble(opp, 'bubble-row')}
        </div>
        ${scoreboard(v)}
      </header>
      <section class="tricks">${tricks}</section>
      ${bubble(v.me, 'bubble-row mine')}
      <section class="hand">${hand}</section>
      <nav class="actions">${buttons}</nav>
      ${overlay(v)}
    </main>`

  seen = { round: v.round, plays: plays.length, bubbles }
}

// A player's latest words since the last card hit the table
function bubbleText(v: PlayerView, p: Player): string | null {
  for (let i = v.log.length - 1; i >= 0; i--) {
    const e = v.log[i]
    if (e.type === 'play') return null
    if (e.player === p) {
      const text = speech(e, v.firstPlayer)
      if (text) return text
    }
  }
  return null
}

function overlay(v: PlayerView): string {
  if (v.phase === 'roundOver') {
    return `<div class="overlay"><div class="panel">
      <p>${roundSummary(v.log, v.me)}</p>
      <button class="primary" data-do="next">${T.nextRound}</button>
    </div></div>`
  }
  if (v.phase === 'matchOver') {
    const mine = v.score[v.me]
    const theirs = v.score[other(v.me)]
    return `<div class="overlay"><div class="panel">
      <h2>${v.winner === v.me ? T.won(mine, theirs) : T.lost(mine, theirs)}</h2>
      <p>${roundSummary(v.log, v.me)}</p>
      <button class="primary" data-do="rematch">${T.rematch}</button>
      <button data-do="menu">${T.menu}</button>
    </div></div>`
  }
  return ''
}

function scoreboard(v: PlayerView): string {
  const row = (p: Player, label: string) =>
    `<div class="score-row"><span>${label}</span><strong>${v.score[p]}</strong>${tally(v.score[p])}</div>`
  return `<div class="score">${row(v.me, T.you)}${row(other(v.me), T.cpu)}</div>`
}

// Fósforos: groups of five drawn as a square plus its diagonal, malas | buenas
function tally(n: number): string {
  const groups = (count: number) => [0, 1, 2].map((g) => group(Math.max(0, Math.min(5, count - g * 5)))).join('')
  return `<span class="tally" aria-hidden="true">${groups(Math.min(n, 15))}<i class="sep"></i>${groups(Math.max(0, n - 15))}</span>`
}

function group(sticks: number): string {
  const lines = ['M2 2H14', 'M14 2V14', 'M14 14H2', 'M2 14V2', 'M2 2L14 14'].slice(0, sticks)
  return `<svg viewBox="0 0 16 16" class="group">${lines.map((d) => `<path d="${d}"/>`).join('')}</svg>`
}
```

```ts
import { apply, newMatch, startRound, view } from './engine.ts'
import type { Player, State } from './engine.ts'
import { chooseAction } from './ai.ts'
import { mount, renderGame, showMenu } from './ui.ts'

const HUMAN: Player = 0
const CPU: Player = 1

let state: State
let cpuTimer: number | undefined

function update() {
  renderGame(view(state, HUMAN))
  if (state.phase === 'playing' && state.turn === CPU) cpuTimer = window.setTimeout(cpuMove, 700 + Math.random() * 500)
}

function cpuMove() {
  const v = view(state, CPU)
  try {
    state = apply(state, CPU, chooseAction(v))
  } catch (err) {
    console.error(err) // never leave the match stuck on an AI bug
    state = apply(state, CPU, v.legal[0])
  }
  update()
}

function startMatch() {
  clearTimeout(cpuTimer)
  state = newMatch(Math.random)
  update()
}

mount(document.getElementById('app')!, {
  onStart: startMatch,
  onAction: (action) => {
    state = apply(state, HUMAN, action)
    update()
  },
  onNextRound: () => {
    state = startRound(state, Math.random)
    update()
  },
  onRematch: startMatch,
  onMenu: () => {
    clearTimeout(cpuTimer)
    showMenu()
  },
})
showMenu()
```

```ts
  environment: 'local' | 'crazygames' | 'disabled'
  game: { gameplayStart(): void; gameplayStop(): void }
  ad: { requestAd(type: 'midgame', callbacks: { adFinished(): void; adError(error: unknown): void }): void }
}

const sdk = (): Sdk | undefined => (window as unknown as { CrazyGames?: { SDK: Sdk } }).CrazyGames?.SDK
let enabled = false

export async function init() {
  const s = sdk()
  if (!s) return
  try {
    await s.init()
    enabled = s.environment !== 'disabled' // outside CrazyGames every SDK call throws
  } catch (err) {
    console.warn('CrazyGames SDK unavailable', err)
  }
}

export function setPlaying(on: boolean) {
  if (!enabled) return
  try {
    if (on) sdk()!.game.gameplayStart()
    else sdk()!.game.gameplayStop()
  } catch (err) {
    console.warn(err)
  }
}

// Always resolves (ad shown, failed or blocked), so a rematch can never get stuck
export function midgameAd(): Promise<void> {
  if (!enabled) return Promise.resolve()
  return new Promise((resolve) => {
    try {
      sdk()!.ad.requestAd('midgame', { adFinished: () => resolve(), adError: () => resolve() })
    } catch {
      resolve()
    }
  })
}
```

- [ ] **Step 2: Conectar el portal en `main.ts` e `index.html`**

`src/main.ts`, completo:

```ts
import { apply, newMatch, startRound, view } from './engine.ts'
import type { Player, State } from './engine.ts'
import { chooseAction } from './ai.ts'
import { mount, renderGame, showMenu } from './ui.ts'
import * as portal from './portal.ts'

const HUMAN: Player = 0
const CPU: Player = 1

let state: State
let cpuTimer: number | undefined

function update() {
  renderGame(view(state, HUMAN))
  if (state.phase === 'matchOver') portal.setPlaying(false)
  if (state.phase === 'playing' && state.turn === CPU) cpuTimer = window.setTimeout(cpuMove, 700 + Math.random() * 500)
}

function cpuMove() {
  const v = view(state, CPU)
  try {
    state = apply(state, CPU, chooseAction(v))
  } catch (err) {
    console.error(err) // never leave the match stuck on an AI bug
    state = apply(state, CPU, v.legal[0])
  }
  update()
}

function startMatch() {
  clearTimeout(cpuTimer)
  state = newMatch(Math.random)
  portal.setPlaying(true)
  update()
}

mount(document.getElementById('app')!, {
  onStart: startMatch,
  onAction: (action) => {
    state = apply(state, HUMAN, action)
    update()
  },
  onNextRound: () => {
    state = startRound(state, Math.random)
    update()
  },
  onRematch: async () => {
    await portal.midgameAd()
    startMatch()
  },
  onMenu: () => {
    clearTimeout(cpuTimer)
    portal.setPlaying(false)
    showMenu()
  },
})
showMenu()
portal.init()
```
