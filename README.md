# Truco

Truco argentino contra la compu.

**[Jugá la última versión](https://federicoemartinez.github.io/truco/)**: se publica sola en cada push a `master`.

## Desarrollo

```sh
npm install
npm run dev     # servidor local
npm test        # tests rápidos
npm run test:sim  # simulaciones de la IA (lentas)
npm run check   # chequeo de tipos
```
